# Patel Dhruv Girishkumar — Personal Portfolio Website

A standalone light-theme responsive website for the IT4048 Version Control with Git and GitHub mini-project. Built with HTML, CSS, and JavaScript; no install or build needed.

## Run locally
1. Extract files and open this project folder in VS Code.
2. Open `index.html` in a web browser, or use VS Code Live Server.
3. Navigate through Home, About, Skills, Projects, Contact; test on mobile and desktop.

## GitHub Pages
1. Create a public GitHub repository named `Dhruv_PortfolioWebsite` under your GitHub account.
2. Upload the **contents of this folder** to the repository root (especially `index.html`). Commit changes to `main`.
3. Go to GitHub repository → Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder: `/(root)` → Save.
4. Once published, your URL will look like `https://YOUR_USERNAME.github.io/Dhruv_PortfolioWebsite/`. Test on your phone and laptop.
5. Submit the public repository link, public live link and PDF report with screenshots according to the teacher's PDF.
